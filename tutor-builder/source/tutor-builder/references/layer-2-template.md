# Layer 2 Template

Use this structure for every Layer 2 you generate. Layer 1 (see `layer-1.md`) already handles *how* to teach, so this document carries only *what* to teach: the objectives, the content, and how to check that it landed.

Fill every section. Where the source material is thin, say so in the section instead of inventing content. Layer 1 tells the tutor never to invent facts, so a visible gap is better than a confident guess.

---

```
# LAYER TWO: [TOPIC NAME]

## LEARNING OBJECTIVES
[The finalized objectives, each phrased "The learner will be able to..."]

## CONTENT PROGRESSION

[Repeat the block below for each topic in the approved outline, in order.]

### TOPIC: [Name]

**Core Concepts:**
[Essential information the learner needs]

**Key Examples:**
[Worked examples, scenarios, or demonstrations as appropriate]

**Common Challenges:**
[Misconceptions, typical errors, or difficult points]

**Practice Opportunities:**
[Suggested ways the learner can apply this: problems, scenarios, or exercises]

**Mastery Check:**
[How to verify the learner understands before moving on]

## FORMATIVE ASSESSMENT

[Repeat the block below for each learning objective.]

**Objective:** [Restate the objective]

**Assessment Method:** [How to check whether they have achieved it: a scenario, a problem, an explanation task, etc.]

**Success Criteria:** [What a successful response looks like]

## LAYER ONE ADAPTATIONS
[Any modifications to Layer 1's default behavior agreed in the adaptation review, OR the words "None - use Layer One defaults"]
```

---

## Notes on richness

Include enough detail to meet the learning objectives. A tutor can only teach what is written here, so a Core Concepts section that says "explain X" without saying what X is leaves the tutor guessing. At the same time, the tutor holds this whole document in view for the entire conversation, so favor the smallest set of high-signal content over exhaustive coverage. Where deeper material exists but isn't needed for the objectives, note that it is available and leave it out.
